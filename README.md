# Telegram → Facebook Mini App Test

1. Host `index.html` at an HTTPS URL you control.
2. Create a Telegram bot with @BotFather.
3. In @BotFather, configure the bot's Mini App/Main Mini App or Menu Button and enter the hosted HTTPS URL.
4. Open the bot in Telegram and launch the Mini App.
5. Tap **Open Facebook**.

The app only opens https://www.facebook.com/ and does not automate Facebook, bypass restrictions, or collect Facebook credentials/cookies.

For production, Telegram's current Mini Apps documentation should be followed because BotFather options can change.
